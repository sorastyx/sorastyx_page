- 原画与作品：Liar-soft / 大石竜子。
- 官方完整同构图版本：https://www.liar.co.jp/ev/denkigai2018s/index.html
- 官方图地址：https://www.liar.co.jp/ev/denkigai2018s/images/new-item_minitape_forest.jpg

- Bangumi 收藏与游戏／动画封面：https://bangumi.tv/user/722867 与 https://api.bgm.tv/v0/users/722867/collections 。封面属于各作品权利人，仅用于作品介绍。
- 固定喜欢作品的 ID：22423、220921、1079、1126、4639、3154、5395。Ever17 使用原版条目 1126，而非另一个重制版条目。
- 已核对 https://bangumi.tv/subject/1079 ：作品名为 I/O；不使用自行展开的 Input / Output 作为作品名或副标题。
